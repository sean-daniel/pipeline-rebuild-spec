1. 水力曲线（规格 §9.3.2）

1.1 水力坡降 / 单位摩阻损失

公式（软件内核，建议主用） — A-09

$$V = C_V\frac{Q}{D_i^2},\quad \mathrm{Re}=\frac{1000\,\mathrm{SG}\,D_i\,V}{\mu_{\mathrm{eq}}},\quad i=\mathrm{sign}(Q)\,g_{\mathrm{fac}}\,C_G\,\frac{f V^{2}}{D_i}$$

其中 \(f\) 由雷诺数与相对粗糙度 \(\varepsilon/D\) 按 A-07（层流 \(64/\mathrm{Re}\)，湍流 Colebrook/Steffensen）计算。

公式（设计标准，似均质流） — (4.3.1-1)

$$i_k=\lambda\frac{V^2}{2gD}\frac{\rho_k}{\rho_s}$$

基本数据

输入来源
\(Q\)工况流量 / 流量计
\(D_i,\varepsilon\)管段几何表
\(\mathrm{SG}\) 或 \(\rho_k\)浓度计 + 固体密度（B4）或密度计
\(\mu_{\mathrm{eq}}\) / \(\tau_B,\eta\)流变试验或多浓度流变表
\(g_{\mathrm{fac}}\)清水/矿浆梯度修正表（GFw/GFs）
\(\lambda\) 或 \(f\)由 Re、粗糙度计算（A-07 或标准 §4.3.2）

说明： HGL 说明文中「坡降线斜率 ∝ \(V^2\)」与上式一致；浓度变稠、流量变小 → 坡降变缓。

$$H(s+\Delta s)=H(s)-i\cdot\Delta s +\Delta H_{\mathrm{pump}}-\Delta H_{\mathrm{valve/local}}$$

若 \(H

$$H=z+\frac{P}{\mathrm{SG}\,\rho_w g},\qquad P=\mathrm{SG}\,\rho_w g\,(H-z)$$

基本数据： 上游边界水头/罐液位或定压；纵断 \(z(s)\)；§1.1 的 \(i\)；泵扬程、阀局部损失（设备表/开度）。

输出： 各里程 \(H,P,V,i\) —— 即规格「静压分布、流速分布、单位阻力损失分布」及承压线对照基础。

1.3 临界流速 \(V_c\) 与沉降判断（§9.3.2 + §9.6.4）

标准表 4.2.2（任选并经试验校核）

刘德忠：

$$V_c=9.5\left[gD\left(\frac{\rho_g-\rho_k}{\rho_k}\right)\omega\right]^{1/3} C_V^{1/6}\left(\frac{\omega_s}{\omega}\right)^{1/6}$$

瓦斯普：

$$V_c=3.113\,C_V^{0.1858} \left[2gD\left(\frac{\rho_g-\rho_k}{\rho_k}\right)\right]^{1/2} \left(\frac{d_{85}}{D}\right)^{1/6}$$

费祥俊：

$$V_c=\frac{2.26}{\sqrt{\lambda}} \left[gD\left(\frac{\rho_g-\rho_k}{\rho_k}\right)\right]^{1/2} C_V^{1/4}\left(\frac{d_{90}}{D}\right)^{1/3}$$

设计要求： \(V_{\mathrm{设计}}>1.10\,V_c\)（标准 4.2.3）；规格报警用 \(1.1/1.0/0.9\,V_c\)（§9.6.4）。

基本数据： 内径 \(D\)、固体密度 \(\rho_g\)、浆体密度 \(\rho_k\)（或浓度）、体积浓度 \(C_V\)、粒径 \(d_{85}/d_{90}\) 或沉速 \(\omega,\omega_s\)（附录 C / 粒度分布）、摩阻系数 \(\lambda\)（费祥俊式）。

判断： 用 B3 的实际 \(V\) 与 \(V_c\) 比较。

1.4 许用压力 / MAOP / 许用 HGL（承压线）

稳态许用内压 — A-45（Barlow）

$$P_{\mathrm{ss}}=2\,f_d\frac{(t-c_a)\sigma_y}{D_o}\,C_P$$

瞬态许用 — A-46

$$P_{\mathrm{tr}}=f_t\,P_{\mathrm{ss}}$$

许用 HGL — A-47

$$H_{\mathrm{allow}}=z+\frac{P_{\mathrm{allow}}}{\mathrm{SG}\,\rho_w g}\quad(\text{单位换算按手册 }C_P\text{)}$$

壁厚设计式（标准，反推/校核用） — (3.2.7)

$$t=\frac{P\cdot D}{2K\phi\sigma_s}+C\cdot S$$

超压警戒值（规格 §9.6.4）

$$P_{\mathrm{警戒}}=\min\bigl(P_{\mathrm{ss}},\;P_{\mathrm{法兰/阀许用}},\;\ldots\bigr)$$

HGL 说明：MAOP 线必须始终在运行水力坡降线之上。

基本数据： \(D_o,t,\sigma_y,f_d,f_t,c_a\)；法兰/阀件铭牌许用压；当地 \(\mathrm{SG}\)；纵断 \(z\)。

1.5 瞬态（水锤 / 阀关 / 流量变更 / 负压区）— §9.3.2(2)、§9.6.5

压力波速（软件） — A-13（Streeter–Wylie 型混合物）

$$a=\sqrt{X/Y}$$

（\(Y\) 含空气、液相、固相、管壁柔性；详见手册。）

波速（标准附录 E.0.1，浆体）

$$a=\left[\rho_k\left( \frac{1-C_v}{E_w}+\frac{C_v}{E_s}+\frac{D_\delta}{E_p\delta} \right)\right]^{-1/2}$$

（\(E_w,E_p,E_s\) 为水/管/物料弹性模量，取值见标准。）

特征阻抗 — A-12

$$B \propto a/A$$

特征线相容（核心步进） — A-14

$$H_P = C\pm - B\,Q_P\quad(\text{C⁺/C⁻ 特征})$$

快速估算（Joukowsky，阀瞬间关闭量级）

$$\Delta P \approx \rho\, a\, \Delta V$$

标准 4.5.1：允许水击压力可按钢管许用应力的 1.1 倍 控制。

基本数据： 管几何与模量、夹气、浓度/密度、\(\Delta t\) 与网格；泵停/启、阀行程时间、流量轨迹；边界条件。

输出： 沿线瞬态最大/最小压力包络、超限点、负压点（规格表格字段）。

2. 清管器位置（§9.5.2）

方法公式/算法基本数据出处
压差法定位监测各站压力阶跃时刻序列，将清管器置于「最近一次阶跃测点」与「下一测点」之间；精细化可用压差波形相关求时延各阀室/泵站出入口压力时序、流量规格正文；管道清管压差定位工程惯例
卡堵判断\(\Delta P_{\mathrm{段}}\) 持续增大 且 \(Q\) 持续下降不恢复 → 卡堵在该两测点之间同上规格 §9.5.2
光纤振动相位/相关时延 → 里程；\(v=\mathrm{d}s/\mathrm{d}t\)DAS 振动规格（可选）

精度指标：定位 ≤3 m；刷新 ≥1 Hz（规格）。

3. 浆水界面位置（§9.5.3）

容积跟踪（工程常用）

设管内截面积分段 \(A_i\)，从始端注入浆体净体积：

$$\mathcal{V}_{\mathrm{slurry}}(t)=\int_0^t\bigl(Q_{\mathrm{in,s}}-Q_{\mathrm{out,s}}\bigr)\,\mathrm{d}\tau$$

界面里程 \(s_{\mathrm{if}}\) 满足：

$$\int_0^{s_{\mathrm{if}}} A(s)\,\mathrm{d}s = \mathcal{V}_{\mathrm{slurry}}(t)$$

可用密度/压力辅助校正（规格：结合始末端流量、压力与密度差）。

基本数据： 始末端体积/质量流量、管段 \(A(s)\)（由 B1/B2）、密度计或浓度突变信号。

指标： 误差 ≤ 0.5%·管段长 + 100 m；≥1 Hz。

4. 泄漏监测（§9.6.1）

4.1 负压波定位

规格给出（忽略流速时）：

$$L=\frac{a L_{\mathrm{总}}-(x_2-x_1)\,a\,\Delta t}{2a}$$

等价常用形式（泄漏点距上游传感器距离 \(x\)）：

$$x=\frac{L+a\,\Delta t}{2} \quad(\Delta t=t_{\mathrm{up}}-t_{\mathrm{dn}},\ \text{符号约定需与测点一致})$$

计及流体流速 \(u\) 时（公开文献改进式）：

$$x=\frac{L(a-u)+\Delta t\,(a^2-u^2)}{2a}$$

基本数据： 上下游压力波形到达时刻差 \(\Delta t\)；波速 \(a\)（§1.5 / A-13）；测点里程 \(x_1,x_2\)；可选当地流速 \(u\)（B3）。

4.2 物料平衡

$$\dot m_{\mathrm{leak}}=\sum \dot m_{\mathrm{in}}-\sum \dot m_{\mathrm{out}}-\frac{\mathrm{d}M_{\mathrm{inv}}}{\mathrm{d}t}$$

稳态近似常令库存变化由压力/温度修正的管存模型给出（RTTM 补偿）。累积：

$$M_{\mathrm{imb}}(t)=\int_0^t \dot m_{\mathrm{leak}}\,\mathrm{d}\tau$$

基本数据： 首站/支线/末站质量流量（或体积流量×密度）；压力温度用于管存。

4.3 RTTM

一维瞬态模型实时求 \(\hat P(s,t),\hat Q(s,t)\)（同 §1.5 特征线），残差：

$$e_P=P_{\mathrm{meas}}-\hat P,\quad e_Q=Q_{\mathrm{meas}}-\hat Q$$

持续超阈则迭代反算泄漏位置与泄漏量（偏差源定位）。

基本数据： 全线边界 P/Q、物性、管网拓扑；同水力模型。

4.4 光纤测漏

由相位差/变化率或声发射时延定位（设备侧算法）；软件侧取里程输出。

4.5 分级用泄漏占比

$$r_{\mathrm{leak}}=\frac{Q_{\mathrm{leak}}}{Q_{\mathrm{nom}}} \quad\Rightarrow\quad \text{蓝 }\le1\%;\ \text{橙 }1\%\sim5\%;\ \text{红 }\ge5\%$$

5. 堵塞监测（§9.6.2）

5.1 预期 vs 实际压降梯度

预期梯度（无堵塞，水力模型）

$$i_{\mathrm{exp}}=\frac{\Delta P_{\mathrm{model}}}{L} \quad\text{或由 §1.1 的 }i(Q,\rho,\ldots)$$

实际梯度

$$i_{\mathrm{act}}=\frac{P_{\mathrm{in}}-P_{\mathrm{out}}}{L}$$
$$\mathrm{ratio}=\frac{i_{\mathrm{act}}}{i_{\mathrm{exp}}}$$

规格：ratio > 1.3 / 1.6 / 2.0 → 蓝 / 橙 / 红。

5.2 堵塞程度（规格公式，符号需买方确认）

$$B\%=\Bigl(1-\frac{1}{\Omega\sqrt{\mathrm{ratio}}}\Bigr)\times 100\%$$

5.3 质量体积平衡（堵塞判别）

由进出口 \(Q,P,T\) 算质量流量与管内质量变化 \(\Delta M\)；堵塞时动量/质量关系与泄漏不同（常表现为上游憋压、下游失压，流量不对称）。与压力梯度法融合定位。

基本数据： 段端压力、流量、温度、密度；§1.1 模型预期压降。

6. 磨蚀监测（§9.6.3）

减薄率

$$\delta_t=\frac{t_0-t(t)}{t_0},\quad \dot t\approx\frac{\mathrm{d}t}{\mathrm{d}t_{\mathrm{calendar}}}$$

剩余寿命（线性近似，常用）

$$T_{\mathrm{rem}}=\frac{t(t)-t_{\mathrm{limit}}}{|\dot t|}$$

\(t_{\mathrm{limit}}\)：设计年限服役终了极限壁厚（强度反算，可用 §1.4 的 \(P,D,K,\sigma_s\) 约束）。

分级： \(\delta_t=20\%/50\%\)；或 \(t\to t_{\mathrm{limit}}\)。

基本数据： 壁厚传感器 \(t(t)\)、原始壁厚 \(t_0\)、设计极限壁厚、历史序列。

7. 超压实时判断（§9.6.4）

已算 \(P_{\mathrm{警戒}}\)（§1.4）后：

$$\frac{P_{\mathrm{meas}}}{P_{\mathrm{警戒}}}\ge 0.6 / 0.8 / 1.0 \quad\Rightarrow\quad\text{蓝/橙/红}$$

基本数据： 全线压力测点；警戒值（设计+管件许用最小值）。

8. 低流速沉降实时判断（§9.6.4）

$$V=Q/A\quad(\text{B3}),\quad V_c=\text{§1.3}$$
$$V<1.1\,V_c\ /\ 1.0\,V_c\ /\ 0.9\,V_c \quad\Rightarrow\quad\text{蓝/橙/红}$$

基本数据： 实时流量、分段内径、物性与粒度（算 \(V_c\)）。

9. 水击在线识别（§9.6.5）

特征量（信号侧）

$$s_P=\frac{\mathrm{d}P}{\mathrm{d}t},\quad P_{\mathrm{peak}}=\max|P|,\quad T_{\mathrm{osc}}=\text{主震荡周期}$$

对照基准

  • 稳态工作压力 \(P_{\mathrm{ss,work}}(s)\)：来自 §1.2 当前稳态解或短时滤波均值
  • 超压警戒：§1.4
  • 汽化临界负压 \(P_{\mathrm{vap}}\)：由温度与浆体物性（饱和蒸汽压 / 工程设定）

正压分级（规格）

条件等级
\(P>1.1\,P_{\mathrm{ss,work}}\)蓝
\(P>1.5\,P_{\mathrm{ss,work}}\)（未超警戒）或 \(P\ge0.8\,P_{\mathrm{警戒}}\)橙
\(P\ge P_{\mathrm{警戒}}\)红

负压分级： 相对 \(P_{\mathrm{vap}}\) 的 0 / 0.8 / 1.0。

基本数据： 高频压力采样；§1.2–1.5 模型包络；物性温度。

10. 加速流与消能（§9.6.6）

10.1 加速流判别 — 标准 **(4.4.1)**

两点能量差大于摩阻损失则可能不满管/加速流：

$$\left(Z_1+\frac{P_1}{\rho_k g}\right) -\left(Z_2+\frac{P_2}{\rho_k g}\right) > i L$$

剩余位能 / 冲击水头（工程定义，对接规格「冲击水头」阈值）

$$H_{\mathrm{surplus}}= \left(Z_1+\frac{P_1}{\rho_k g}\right) -\left(Z_2+\frac{P_2}{\rho_k g}\right) - i L$$
$$\frac{H_{\mathrm{surplus}}}{H_{\mathrm{lim}}}\ge 0.6/0.8/1.0 \quad\text{或高点 }P<0 \quad\Rightarrow\quad\text{蓝/橙/红}$$

基本数据： 两点高程、压力、段长、§1.1 的 \(i\)、\(\rho_k\)；阈值 \(H_{\mathrm{lim}}\)（项目配置）。

10.2 孔板消能水头 — 标准 **(4.4.2)**

$$\Delta h=K_{\mathrm{QK}} Q^2,\quad K_{\mathrm{QK}}=6.3755\times10^{-9}\frac{(1-\beta^2)(1.142-\beta^2)}{d^4},\quad \beta=d/D$$

基本数据： 流量 \(Q\)、孔径 \(d\)、管径 \(D\)、孔板投入组合。

10.3 消能站站后压力阈值

规格：站前阈 = \(P_{\mathrm{警戒}}\)；站后阈 = 由下游工况水力反算（保证到达终端微正压/进罐压 + 下游许用），即用 §1.2 从终端边界向上游反推所需站后最小/最大压。

浓度/流量：与设计窗 \([C_{\min},C_{\max}]\times[Q_{\min},Q_{\max}]\) 比较（直接阈值，无需复杂公式）。

11. 泵功率 / 能耗优化相关（§9.8.2）

电机功率（标准泵送章常用）

$$N=\frac{\rho g Q H}{1000\,\eta_{\mathrm{pump}}\eta_{\mathrm{motor}}} \quad(\text{单位按标准条文统一})$$

优化陈述（规格）

$$\min\ \frac{E_{\mathrm{water}}+E_{\mathrm{elec}}}{m_{\mathrm{solids}}} \quad\text{s.t.}\quad V\ge 1.1 V_c,\ P\le P_{\mathrm{警戒}},\ \text{水力扰动约束}$$

决策变量：泵转速（或频率）、经济流速；硬约束调用 §1.3、§1.4、§1.2。

基本数据： 泵特性曲线、实测功率/转速、流量浓度、§1 水力结果。

12. 智能预警 / 模拟（§9.7）— 计算形态

项计算内容基本数据

15. 落地注意（避免误用）

  1. 临界流速无单一「真理公式」：标准列三式供选用，须环管试验或类似工程校核后再进报警阈值。
  2. A-09 与标准 (4.3.1) 单位制不同（软件常用工程常数）；重建时内核定死一套 SI，界面再换算。
  3. 堵塞 B% 公式中 \(\Omega\) 规格排版不清，实现前与买方书面确认。
  4. 光纤类以设备算法为准，本清单只保留里程/速度接口。
  5. 智能预警/预测无封闭解析式，属数据驱动；水力硬约束仍回到本清单 §1–§10。
